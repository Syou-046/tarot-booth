# 仕様 — 占い師のタロット

## 目的と使われ方

映画『魔法使いちゃんは素直になれやしない』の完成上映会(2026年10月17日・新川あおやぎ公園)に出す占いブースのためのタロット占い。当日はスタッフがタブレットを持って来場者に遊んでもらう。来場者の中心は地域の家族と子ども。上映会のあとは、同じものを映画公式サイトに組み込み、誰でも自分の端末で遊べるようにする。

占いは楽しむためのもので、未来を断定しない。この姿勢は画面の注意書きと保存画像にも入れる。

## 参考にするもの

流れと機能は waltzingmouse.com のタロット占いに合わせる。あのサイトはカードを引いて並べて保存するところまでを担い、解読は内蔵していない。本作も当面はこれに倣う。

## 確定していること

デッキはライダー・ウェイト版の 78 枚(大アルカナ 22 枚+小アルカナ 56 枚)。1909 年版の絵柄はパブリックドメインとして扱う。現在の画像は npm パッケージ `@cometpisces/tarot-kit-images` 由来の 300×527px で、公式サイト公開までに高解像度版へ差し替える予定。

逆位置あり。1 枚ごとに独立して 50% の確率で逆位置になり、絵柄を上下反転して表示し、カード名の下に「正位置/逆位置」を出す。

一回の占いの流れは次の通り。聞きたいことを心の中で思い浮かべる → 引く枚数を選ぶ(1〜7 枚、初期値 3 枚)→ カードを混ぜる → 裏向きに扇状に広がったカードから枚数分を順に選ぶ → 並んだカードを一枚ずつタッチしてめくる → 必要なら補足カードを 1 枚ずつ引く(最大 3 枚)→ 結果を画像で保存する → 新しく占う。

スプレッドは「自由線形スプレッド」(選んだ順に横一列、位置名は「1まいめ」「2まいめ」…)。「過去・現在・未来」は使わない。

抽選は暗号学的乱数による一様・非復元抽出。演出の揺れと抽選結果は完全に切り離す。

AI の API を使った解読は不採用。

結果は URL に書き出し、その URL を開くと同じ結果を再表示できる。ブースモード(`?booth=1`)では結果画面で 90 秒操作がなければ最初の画面に戻る。

会場のネット環境に左右されないよう、ブースでは通信なしで動作すること。

## 未決事項

この節にある項目は、しょうが決めるまで実装しない。

スプレッドの種類。waltzingmouse の「牌陣を変更」に並ぶ選択肢と位置名をしょうが確認して共有する予定。共有されたら DECISIONS に記録し、その内容どおりに実装する。

解読の扱い。解読を出すか出さないか、出すなら事前に書いた文章か、公式サイト版だけ「自分の AI に貼る用のプロンプトをコピー」を付けるか。

来場者が結果を持ち帰る方法。タブレットで画像保存しても来場者の手元には残らない。結果 URL を QR コードで表示してスマホで読み取ってもらう案がある。

公式サイトの基盤(WordPress / STUDIO / Wix / 自前など)と、組み込み方(同じページに埋め込むか、サブドメインで独立させるか)。

ブース用タブレットの機種と OS、全画面表示の方法。

映画のキャラクター(占い師など)を画面に登場させるか。登場させる場合は原作者の許諾が必要。

高解像度カード画像の入手元。
