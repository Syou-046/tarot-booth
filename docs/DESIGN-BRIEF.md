## 技術備注

### sizeSlots()（app.js）
計算 spread 區域裡每個 slot 的寬度 `--sw`。需要保證 spread + fan 加起來不超出螢幕。

### fanLayout(mode)（app.js）
把 78 張牌排成扇形。`mode="stack"` 是洗牌動畫（牌堆在一起），`mode="fan"` 是展開。目前的問題是牌的大小和位置計算會讓牌超出 `.fan` 容器。

需要的行為：
- 根據 `.fan` 容器的實際寬高決定排幾排、每張牌多大
- 每張牌的位置必須在容器範圍內（不能被 overflow:hidden 切掉）
- 在電腦寬螢幕上可能 2-3 排，iPad 上 2 排，手機上 2-3 排較小的牌

### CSS 佈局
目前用 grid + position:absolute 混合，panel 和 fan 在同一個 `.table` 裡面疊加。歡迎畫面時 fan 是空的、panel 顯示 setup；選牌時 panel 隱藏、fan 顯示。這個結構可以保留也可以改，只要功能一樣。
